# Отчет по лабораторной работе 7

## Тема
Сериализация и десериализация объектов с использованием модуля pickle.

## Постановка задачи
1. Создать класс для хранения данных игрока (имя, счет, уровень).
2. Реализовать функции сохранения и загрузки объекта игрока в/из файла с использованием модуля `pickle`.
3. Продемонстрировать процесс сериализации и десериализации объекта.

## Структура проекта
- `main.py` — основной скрипт с классом игрока и функциями работы с pickle.
- `player.pkl` — бинарный файл, содержащий сериализованный объект игрока.

## Описание реализации

### Класс `playerData`
```python
class playerData:
    def __init__(self, player_name, score, level):
        self.player_name = player_name
        self.score = score
        self.level = level
    
    def display(self):
        print(f"Player: {self.player_name}, score: {self.score}, level: {self.level}")
```
Класс для хранения данных игрока. Конструктор принимает имя игрока, счет и уровень. Метод `display()` выводит информацию об игроке в консоль.

### Функция `save_game()`
```python
def save_game():
    with open("LR 7/player.pkl", "wb") as f:
        pickle.dump(player, f)
```
Функция сохраняет объект `player` в бинарный файл `player.pkl`. Используется менеджер контекста `with open(..., "wb")` для открытия файла в режиме записи бинарных данных. Функция `pickle.dump()` сериализует объект и записывает его в файл.

### Функция `load_game()`
```python
def load_game():
    with open("LR 7/player.pkl", "rb") as f:
        return pickle.load(f)
```
Функция загружает объект из файла `player.pkl`. Файл открывается в режиме чтения бинарных данных (`"rb"`). Функция `pickle.load()` десериализует объект из файла и возвращает его.

### Основной код
```python
player = playerData("player", 0, 1)
save_game()
player = load_game()
player.display()
```
1. Создается объект игрока с начальными значениями: имя "player", счет 0, уровень 1.
2. Объект сохраняется в файл с помощью `save_game()`.
3. Объект загружается из файла с помощью `load_game()`.
4. Выводится информация об игроке через метод `display()`.

## Особенности работы с pickle
- **Сериализация** — процесс преобразования объекта Python в поток байтов для сохранения в файл или передачи по сети.
- **Десериализация** — обратный процесс восстановления объекта из потока байтов.
- Файлы pickle имеют расширение `.pkl` и содержат бинарные данные.
- Модуль `pickle` позволяет сохранять и загружать сложные объекты Python, включая пользовательские классы.

## Пример использования
При запуске программы:
1. Создается объект игрока.
2. Объект сериализуется и сохраняется в `player.pkl`.
3. Объект десериализуется из файла.
4. Выводится информация: `Player: player, score: 0, level: 1`
